# TechStore

Proyecto Java 21 con Maven y menús por consola de texto mediante `JOptionPane`.

## Ejecución

1. Abrir la carpeta `TechStore` como proyecto Maven en IntelliJ IDEA.
2. Configurar JDK 21.
3. Ejecutar `src/main/java/co/edu/uniquindio/poo/app/Main.java`.

## Navegación

Todos los menús de navegación solicitan escribir un número. Esto incluye el menú principal, los submenús, categorías, métodos de pago y la selección de productos durante la creación de una factura.

## Facturas

Las facturas reciben un código numérico secuencial como `1001`, `1002`, etc. La factura de ejemplo inicial utiliza el código `1000`. Durante la creación se deben seleccionar productos mediante sus números y agregar al menos uno antes de guardar la factura.
